# 🎙️ Podcast Library

> **30 carefully curated podcasts** across personal growth, business strategy, and developer craft. Last updated: 2026-03-20

---

## 🧭 How to Use This

- **Deep session (1–2×/week):** Pick one long-form episode — Acquired, Tim Ferriss, Knowledge Project, SE Radio
- **Maintenance session (2–4×/week):** Pick a shorter show — Developer Tea, HBR IdeaCast, Huberman Essentials
- **Daily (3–10 min):** The Daily Stoic — morning calibration

**The Learning Loop:**
Listen → Capture 5 bullets + 1 behavior to try → Implement within 48 hours → Write a 5-min after-action review

### 1. Huberman Lab
- **Host:** Andrew Huberman (Stanford neuroscientist)
- **Frequency:** Semiweekly (Mondays)
- **Length:** 40 min (Essentials) → 1h40+ (Toolkits)
- **Best for:** Sleep, focus, motivation, habits — the upstream "capacity" skills
- **Best episodes:**
	- *Sleep Toolkit* (1h40) — build a customizable sleep protocol
	- *Focus Toolkit* (1h46) — entering, sustaining, and exiting focus bouts

- **Spotify:** [Huberman Lab](https://open.spotify.com/show/79CkJF3UJTHFV8Dse3Oy0P)
