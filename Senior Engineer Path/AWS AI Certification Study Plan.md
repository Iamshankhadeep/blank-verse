# AWS AI Certification Study Plan

> [!success] Current target order
> 1. [[AWS Certifications/02 - AWS Certified AI Practitioner]]
> 2. [[AWS Certifications/07 - AWS Certified Machine Learning Engineer - Associate]]
> 3. [[AWS Certifications/12 - AWS Certified Generative AI Developer - Professional]]
> 4. [[AWS Certifications/03 - AWS Certified Solutions Architect - Associate]]

## Goal
Finish the AI-first AWS path in a sensible order without trying to brute-force the hardest cert first.

## Phase 1: AI Practitioner first

### Useful links
- Course: https://www.udemy.com/course/aws-ai-practitioner-certified/?couponCode=JUST4U02223
- Practice questions: https://www.whizlabs.com/aws-certified-ai-practitioner/
- Exam guide: https://d1.awsstatic.com/training-and-certification/docs-ai-practitioner/AWS-Certified-AI-Practitioner_Exam-Guide.pdf?p=cert&c=ai&z=3

### Week 1, Foundations
- Learn core AI, ML, and GenAI vocabulary.
- Understand supervised learning, unsupervised learning, inference, fine-tuning, embeddings, hallucinations, and responsible AI.
- Read the official exam guide.
- Create one page of your own glossary notes.

### Week 2, AWS AI services map
- Study Bedrock, SageMaker, Amazon Q, Rekognition, Textract, Comprehend, and Lex at a high level.
- Learn what each service is for and where it fits.
- Make a comparison note for overlapping services.
- Do short quizzes after each topic.

### Week 3, Responsible AI and use cases
- Study governance, privacy, bias, guardrails, and evaluation concepts.
- Learn common business use cases for AWS AI services.
- Review weak areas from Week 1 and Week 2.
- Take your first timed practice test.

### Week 4, Exam prep and review
- Review all wrong answers from practice tests.
- Revisit confusing AWS services.
- Do 2 to 3 timed practice sessions.
- Schedule the AI Practitioner exam once practice scores feel stable.

## Phase 2: Machine Learning Engineer Associate

### Useful links
- Course: https://www.udemy.com/course/aws-certified-machine-learning-engineer-associate-mla-c01/
- Practice questions: https://www.whizlabs.com/aws-certified-machine-learning-engineer-associate/
- Exam guide: https://d1.awsstatic.com/training-and-certification/docs-machine-learning-engineer-associate/AWS-Certified-Machine-Learning-Engineer-Associate_Exam-Guide.pdf

### Week 5, ML workflow basics on AWS
- Study the end-to-end ML lifecycle.
- Learn data prep, feature engineering, training, validation, deployment, and monitoring.
- Get comfortable with SageMaker concepts.
- Build a simple ML workflow map note.

### Week 6, SageMaker depth
- Study training jobs, notebooks, pipelines, endpoints, batch transform, tuning jobs, and model registry.
- Learn when to use real-time inference vs batch inference.
- Do hands-on practice where possible.

### Week 7, Data and MLOps
- Study S3, Glue, Athena, IAM, CloudWatch, Lambda, and event-driven ML support patterns.
- Understand drift, retraining, monitoring, and versioning.
- Practice architecture-style questions.

### Week 8, Review and practice exams
- Focus on weak domains only.
- Do timed mocks.
- Build short summary notes for deployment options, tuning, and model ops.
- Book the exam when scores are consistent.

## Phase 3: Generative AI Developer Professional

### Useful links
- Course: https://www.udemy.com/course/ultimate-aws-certified-generative-ai-developer-professional/
- Practice questions: https://www.whizlabs.com/aws-certified-generative-ai-developer-professional/
- Exam guide: https://docs.aws.amazon.com/aws-certification/latest/ai-professional-01/ai-professional-01.html

### Week 9, GenAI architecture on AWS
- Study Bedrock deeply.
- Learn prompt engineering, embeddings, vector stores, RAG, and model evaluation.
- Understand GenAI system components end to end.
- Build one small architecture note for a chatbot or knowledge assistant.

### Week 10, Safety, governance, and trade-offs
- Study moderation, PII handling, hallucination reduction, guardrails, and governance.
- Learn cost vs latency vs quality trade-offs.
- Compare common architecture choices for GenAI apps.

### Week 11, Hands-on build week
- Build a small GenAI project on AWS or at least design it in detail.
- Example: a document Q&A assistant using embeddings and retrieval.
- Write down architecture decisions and service choices.

### Week 12, Final review and exam readiness
- Do scenario-heavy practice questions.
- Review weak spots in Bedrock, RAG, evaluation, and safety.
- Make one final cheat sheet note.
- Schedule the exam when your mocks stop swinging wildly.

## Weekly routine

### 5-day study rhythm
- **Day 1:** Learn concepts
- **Day 2:** Study AWS services
- **Day 3:** Hands-on or architecture practice
- **Day 4:** Practice questions
- **Day 5:** Review mistakes and make notes

### Minimum pace
- 60 to 90 minutes on weekdays
- 2 to 3 hours on one weekend day

## Rules for this plan
- Do not start with GenAI Professional first. That’s ego bait.
- Finish AI Practitioner first to build vocabulary and confidence.
- Use notes aggressively. If you learned it, write it down.
- Mock test mistakes matter more than passive reading.
- Hands-on beats rewatching videos.
