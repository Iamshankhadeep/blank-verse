# AWS Certified Data Engineer - Associate

> [!info] Level
> Associate

> [!summary] Exam shape
> 65 questions, 130 minutes, passing score 720

## Who this is for
Data engineers and analytics engineers building pipelines and data systems on AWS.

## Core focus areas
- Glue, Redshift, S3, Athena, Kinesis, and MSK
- ETL and ELT patterns
- OLTP vs OLAP
- data lake vs data warehouse
- cost and performance trade-offs in analytics

## Prep advice
- Know the core data services cold.
- Study data architecture patterns, not just service definitions.
- Understand when to use streaming, batch, warehouse, or lake patterns.
