# AWS Certified Security - Specialty

> [!info] Level
> Specialty

> [!summary] Exam shape
> 65 questions, 170 minutes, passing score 750

## Who this is for
Security engineers and cloud engineers specializing in AWS security.

## Core focus areas
- IAM
- KMS
- CloudTrail
- CloudWatch
- Security Hub
- Inspector
- WAF, Shield, and secure architecture patterns

## Prep advice
- Depth matters more than breadth.
- When in doubt, the most secure valid design often wins.
- Know secure data, identity, and network patterns well.
