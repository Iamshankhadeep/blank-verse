# AWS Certified Cloud Practitioner

> [!info] Level
> Foundational

> [!summary] Exam shape
> 65 questions, 90 minutes, passing score 700

## Who this is for
Beginners, non-cloud engineers, and anyone who needs AWS baseline literacy.

## Core focus areas
- cloud concepts
- shared responsibility model
- core AWS services
- pricing and billing basics
- high-level architecture understanding

## Prep advice
- Study breadth over depth.
- Learn what major AWS services do and when they are used.
- Practice distinguishing similar services at a high level.
