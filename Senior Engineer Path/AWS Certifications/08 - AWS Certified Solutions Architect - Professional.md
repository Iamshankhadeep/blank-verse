# AWS Certified Solutions Architect - Professional

> [!info] Level
> Professional

> [!summary] Exam shape
> 75 questions, 180 minutes, passing score 750

## Who this is for
Experienced architects designing complex AWS systems with real trade-offs.

## Core focus areas
- advanced architecture design
- performance, resilience, and security
- migration and modernization
- cost optimization
- difficult scenario-based reasoning

## Prep advice
- Expect harder wording and more subtle answer choices.
- Watch for keywords like managed, low latency, minimal operations, and cost-effective.
- Flag long questions and return later if needed.
