# AWS Certified CloudOps Engineer - Associate

> [!info] Level
> Associate

> [!summary] Exam shape
> 65 questions, 130 minutes, passing score 720

## Who this is for
Ops, SRE, infra, and platform engineers responsible for running AWS systems well.

## Core focus areas
- monitoring and observability
- CloudWatch, CloudTrail, and CloudFormation
- VPC, NACLs, and security groups
- troubleshooting
- operational excellence

## Prep advice
- Hands-on practice matters a lot here.
- Practice alarms, logging, scaling, IAM, and VPC setup.
- Learn how to diagnose failures, not just deploy resources.
