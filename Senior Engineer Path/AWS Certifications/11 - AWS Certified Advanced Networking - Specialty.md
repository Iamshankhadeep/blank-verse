# AWS Certified Advanced Networking - Specialty

> [!info] Level
> Specialty

> [!summary] Exam shape
> 65 questions, 170 minutes, passing score 750

## Who this is for
Engineers working on hybrid cloud, enterprise networking, and deep AWS connectivity design.

## Core focus areas
- VPC architecture
- Direct Connect
- Transit Gateway
- VPN
- Route 53
- hybrid connectivity
- routing and network optimization

## Prep advice
- This is one of the harder AWS exams.
- Practice hybrid and multi-network scenarios.
- Read carefully because one word can change the right answer.
