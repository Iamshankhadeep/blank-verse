# AWS Certified DevOps Engineer - Professional

> [!info] Level
> Professional

> [!summary] Exam shape
> 75 questions, pro-level scenario-heavy exam, passing score 750

## Who this is for
Senior DevOps and platform engineers working with automation-heavy AWS environments.

## Core focus areas
- CI/CD
- infrastructure as code
- automation
- monitoring and operations
- ECS, EKS, ECR, and event-driven delivery

## Prep advice
- Combine knowledge from Developer Associate and CloudOps Associate.
- Pay attention to keywords like real-time, automatically, private, and low latency.
- Use mock exams to build timing discipline.
