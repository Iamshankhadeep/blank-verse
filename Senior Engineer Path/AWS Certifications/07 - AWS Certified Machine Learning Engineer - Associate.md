# AWS Certified Machine Learning Engineer - Associate

> [!info] Level
> Associate

> [!summary] Exam shape
> 65 questions, 130 minutes, passing score 720

## Who this is for
Engineers implementing ML systems on AWS, especially with SageMaker.

## Core focus areas
- SageMaker workflows
- data prep and feature engineering
- training, tuning, and deployment
- model versioning and drift
- MLOps basics on AWS

## Prep advice
- Treat this as a SageMaker-heavy exam.
- Be comfortable with training, deployment, and model operations.
- Understand the surrounding AWS services used in ML pipelines.
