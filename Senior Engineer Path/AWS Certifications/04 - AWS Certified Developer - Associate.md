# AWS Certified Developer - Associate

> [!info] Level
> Associate

> [!summary] Exam shape
> 65 questions, 130 minutes, passing score 720

## Who this is for
Developers building, deploying, and integrating applications on AWS.

## Core focus areas
- application development on AWS
- CodeBuild, CodePipeline, and CodeDeploy
- deployment strategies
- AWS SDK and service integration patterns
- application delivery workflows

## Prep advice
- Build a small CI/CD pipeline end to end.
- Study deployment strategies and trade-offs.
- Focus more on developer tooling than on broad architecture theory.
